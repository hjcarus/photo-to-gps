# 사진 GPS 위치 확인

사진을 올리면 EXIF의 GPS 정보를 읽어 **도분초 → 십진수**로 변환해 위도·경도를 보여주고,
그 위치를 지도에 표시합니다. 옆에는 클릭한 지점의 좌표를 알려주는 위성지도가 있습니다.

## 기능

1. **업로드** — 업로드 버튼, 화면 아무 곳에나 **드래그 앤 드롭**, `Ctrl+V` 붙여넣기
2. **GPS 추출** — EXIF의 도분초를 `도 + 분/60 + 초/3600`으로 계산(S·W는 음수).
   위도·경도를 소수점 6자리로 표시하고 원본 도분초도 함께 보여줌. 각 값 옆 **복사 버튼**
3. **사진 위치 지도** — 촬영 지점에 핀 표시
4. **위성지도** — 클릭하면 그 지점에 핀이 찍히고 위도·경도가 아래에 표시, 역시 **복사 버튼** 제공
5. **좌표 직접 입력** — 사진 없이 위도·경도를 넣어 위성지도에 핀을 찍음

## 좌표 직접 입력

오른쪽 아래 **좌표 직접 입력** 칸에 값을 넣고 `지도에 핀 찍기`(또는 `Enter`)를 누르면
그 자리에 핀이 찍히고 지도가 줌 18로 이동합니다. 위의 **클릭한 지점** 좌표도 같은 값으로
채워지므로 복사 버튼을 그대로 쓸 수 있습니다.

받아들이는 형태:

| 입력 | 해석 |
|---|---|
| `37.690486` | 십진수 |
| `-33.8688` | 남위·서경은 음수 |
| `37° 41' 25.7" N` | 도분초 (`37 41 25.7 N`처럼 기호 없이도 됨) |
| `37.690486, 126.518861` | 위도 칸에 둘을 함께 붙여넣으면 자동으로 나눠 넣음 |

도분초로 넣으면 핀을 찍은 뒤 칸의 값이 십진수로 바뀌어, 변환 결과를 바로 확인할 수 있습니다.
위도 ±90, 경도 ±180을 벗어나면 핀을 찍지 않고 안내 문구를 보여줍니다.

## 지도 구성

| 패널 | 지도 | 비고 |
|---|---|---|
| 왼쪽 · 사진의 위치 | 구글지도 (키가 있을 때) / OSM | 도로·지명 표시용 |
| 오른쪽 · 위성지도 | 항상 Esri World Imagery | 클릭 → 좌표, 사진을 올리면 줌 18 |

사진을 올리면 위성지도가 **줌 18**로 바로 확대됩니다. Esri World Imagery는 줌 19 영상이
없는 지역이 꽤 있어서 19로 열면 `Map data not yet available` 타일이 뜨는 경우가 많기
때문입니다. 영상이 있는 곳에서는 손으로 19까지 더 확대할 수 있습니다.

배율은 스크립트 상단의 상수 두 개로 조절합니다.

```js
const SAT_OPEN_ZOOM = 18;   // 사진을 올렸을 때 자동으로 맞춰지는 배율
const SAT_MAX_ZOOM  = 19;   // 손으로 확대할 수 있는 최대 배율
```

위성지도에 구글을 쓰지 않는 이유가 있습니다. **국내는 구글 위성영상이 줌 15까지만 제공되어,
그 이상 확대하면 영상이 사라지고 바탕 도로지도만 남습니다.** Esri World Imagery는 국내도
최대 배율까지 영상이 있어서 이쪽을 씁니다. 덤으로 구글 지도 로드가 페이지당 1회로 줄어
무료 한도를 절반만 쓰게 됩니다.

## 구글지도 사용하기

왼쪽 지도를 구글지도로 쓰려면 API 키가 필요합니다. 키가 없어도 모든 기능은 그대로 동작합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고
   **Maps JavaScript API**를 사용 설정합니다.
2. **사용자 인증 정보 → API 키 만들기**로 키를 발급받습니다.
3. 키의 *애플리케이션 제한사항*을 **HTTP 리퍼러(웹사이트)** 로 두고,
   이 페이지를 올린 주소(예: `https://<사용자명>.github.io/*`)를 허용 목록에 추가하세요.
4. 페이지 상단 입력칸에 키를 넣고 **적용**을 누릅니다. 키는 브라우저에만 저장되며
   저장소에는 올라가지 않습니다.

### 요금 걱정 없이 쓰기

Dynamic Maps는 월 10,000회까지 무료이고, 이 페이지는 **페이지를 한 번 열 때 1회**를
사용합니다(지도 확대·이동·핀 표시는 과금되지 않습니다). 그래도 상한을 걸어두려면:

- **할당량** → Maps JavaScript API → `Map loads per day` 를 **320** 으로 설정하면
  월 최대 9,920회로 무료 한도 안에 묶여 요금이 0원으로 고정됩니다.
- 예산(Budget) 설정은 *알림만* 보낼 뿐 과금을 막지 못하니, 반드시 할당량 쪽을 거세요.

키를 넣지 않으면 왼쪽 지도도 OpenStreetMap으로 대체되며,
좌표 표시·핀·복사 기능은 똑같이 동작합니다.

## 실행

별도의 빌드 과정이 없습니다. `index.html`을 브라우저로 열거나, 정적 호스팅에 그대로 올리면 됩니다.

## 사용 라이브러리

- [exifr](https://github.com/MikeKovarik/exifr) — EXIF 파싱
- [Leaflet](https://leafletjs.com/) — 구글 API 키가 없을 때의 대체 지도
- 위성 영상: Esri World Imagery / 일반 지도: OpenStreetMap

## 참고

- 사진은 어디에도 업로드되지 않습니다. 모든 처리는 브라우저 안에서 이루어집니다.
- 메신저나 SNS를 거친 사진은 EXIF가 지워져 GPS 정보가 없을 수 있습니다.

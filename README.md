# 사진 GPS 위치 확인

사진을 올리면 EXIF의 GPS 정보를 읽어 **도분초 → 십진수**로 변환해 위도·경도를 보여주고,
그 위치를 지도에 표시합니다. 옆에는 클릭한 지점의 좌표를 알려주는 위성지도가 있습니다.

## 기능

1. **업로드** — 업로드 버튼, 화면 아무 곳에나 **드래그 앤 드롭**, `Ctrl+V` 붙여넣기
2. **GPS 추출** — EXIF의 도분초를 `도 + 분/60 + 초/3600`으로 계산(S·W는 음수).
   위도·경도를 소수점 6자리로 표시하고 원본 도분초도 함께 보여줌. 각 값 옆 **복사 버튼**
3. **사진 위치 지도** — 촬영 지점에 핀 표시
4. **위성지도** — 클릭하면 그 지점에 핀이 찍히고 위도·경도가 아래에 표시, 역시 **복사 버튼** 제공

## 구글지도 사용하기

구글지도 JavaScript API는 API 키가 필요합니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고
   **Maps JavaScript API**를 사용 설정합니다.
2. **사용자 인증 정보 → API 키 만들기**로 키를 발급받습니다.
3. 키의 *애플리케이션 제한사항*을 **HTTP 리퍼러(웹사이트)** 로 두고,
   이 페이지를 올린 주소(예: `https://<사용자명>.github.io/*`)를 허용 목록에 추가하세요.
4. 페이지 상단 입력칸에 키를 넣고 **적용**을 누릅니다. 키는 브라우저에만 저장됩니다.

키를 넣지 않으면 Esri 위성영상과 OpenStreetMap 지도로 자동 대체되며,
좌표 표시·핀·복사 기능은 똑같이 동작합니다.

## 실행

별도의 빌드 과정이 없습니다. `index.html`을 브라우저로 열거나, 정적 호스팅에 그대로 올리면 됩니다.

## 사용 라이브러리

- [exifr](https://github.com/MikeKovarik/exifr) — EXIF 파싱
- [Leaflet](https://leafletjs.com/) — 구글 API 키가 없을 때의 대체 지도
- 위성 영상: Esri World Imagery / 일반 지도: OpenStreetMap

## 참고

- 사진은 어디에도 업로드되지 않습니다. 모든 처리는 브라우저 안에서 이루어집니다.
- 메신저나 SNS를 거친 사진은 EXIF가 지워져 GPS 정보가 없을 수 있습니다.
